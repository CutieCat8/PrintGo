# A1: ตรวจ PromptPay QR ด้วยมือถือ

1. ใส่เลขพร้อมเพย์ของ PrintGo ใน `PLATFORM_PROMPTPAY_ID` ของ `.env.local`
   (เบอร์โทร 10 หลัก หรือเลขประจำตัว 13 หลัก เป็นตัวเลขติดกัน)
   ไม่ต้องส่งเลขจริงในแชท และไม่ commit ไฟล์ env
2. รันจากรากโปรเจกต์:

   ```bash
   npm run payment:preview
   ```

3. เปิดไฟล์ PNG ตามพาธที่คำสั่งแสดง รูปอยู่ในโฟลเดอร์ชั่วคราวเฉพาะผู้ใช้
   ไม่ได้อยู่ใน `public` หรือ Git และไม่มีการเปิดเว็บ/API ให้คนอื่นเข้าถึง
4. สแกนด้วยแอปธนาคาร ตรวจชื่อบัญชี PrintGo และยอด **1.23 บาท**
   ไม่ต้องกดยืนยันโอน การสร้างรูปไม่ได้บันทึก payment หรือเปลี่ยนสถานะออเดอร์
5. บันทึกชื่อแอป วันที่ตรวจ ชื่อบัญชีตรงหรือไม่ และยอดตรงหรือไม่
   ไม่ต้องแนบเลขบัญชีหรือข้อมูลส่วนตัวในรายงาน แล้วลบไฟล์ PNG

รูป QR มีข้อมูลบัญชีอยู่ภายใน จึงไม่ควรอัปโหลดรูปจริงใน PR หรือแชท
เลขสมมติใน automated tests ใช้ตรวจรูปแบบเท่านั้น ไม่ใช้ยืนยันชื่อบัญชีจริง

คำสั่ง preview ใช้ Vitest ที่มีอยู่ในโปรเจกต์เพื่อเรียก provider TypeScript ตัวจริง
ส่วน preview ถูกข้ามในการรัน tests ปกติ ต้องสั่งผ่าน `payment:preview` เท่านั้น
รายละเอียดการตรวจสลิป A2 อยู่ใน [slip/README.md](slip/README.md)
