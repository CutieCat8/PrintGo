แนวคิด

  • เก็บไว้แค่ 3 ตัวละคร: เครื่องปริ้นหน้ายิ้ม กระดาษ และไรเดอร์ ไม่มีเครื่องซ้ำ ไม่มีกระดาษปลิวเต็มจอ
  • เล่าเรื่องเส้นเดียวจากซ้ายไปขวา: เครื่องปริ้นพิมพ์ → กระดาษออกมา → ไรเดอร์ขี่ไปตามถนนเส้นเดียว → ถึงบ้าน ตรงกับ "Your file goes in. Your print comes home."
  • ธีมเดียวกับแอป (หมึกดำ ขาวนวล เขียวฟอเรสต์) มีสีกล่องพัสดุเป็นสีเดียวที่เพิ่มเข้ามา
  • ปุ่มหลัก "สั่งปริ้น" ใหญ่สุด เพราะลูกค้ากดบ่อยที่สุด
